Unified Scenario Study of Fanaroff-Riley Galaxy and Blazar

Radio galaxies have two subclasses: Fanaroff–Riley type I (FR Is) and type II (FR IIs). Within the radio-loud AGN unification framework, FR Is are considered the misaligned counterparts of BL Lacertae objects (BL Lacs), while FR IIs correspond to misaligned flat-spectrum radio quasars (FSRQs).

In this work, we analyze 2124 sources, including 75 FR Is, 147 FR IIs, 1142 BL Lacs, and 760 FSRQs. After deriving their kinetic jet power (), we classify the sample into two classes using the Bayesian Information Criterion (BIC) and Gaussian Mixture Model (GMM) methods.

The BIC analysis indicates that the sample is optimally divided into two classes. The GMM analysis identifies a crossing point at . Sources are therefore separated into a weak class () and a strong class (). By incorporating the core-dominance parameter (), three changing-look blazars are identified near the SVM dividing line.


Fermi blazar Light Curve and Spectrum Enerty Distribution data analysis
In this work, all data were obtained from the Fourth Fermi-LAT Source Catalog Data Release 4 (4FGL-DR4), from which a total of 3933 blazars were collected.

The data used in this work were analyzed within a circular region of interest (ROI) of radius 5° centered on the target source. Events in the energy range of 0.1–300 GeV were selected. The P8R3_SOURCE_V3_v1 instrument response function (IRF) was adopted following the recommendations of the Fermi documentation.

To minimize contamination from the Earth’s limb, events with zenith angles larger than 90° were excluded. Only data satisfying DATA_QUAL > 0 && LAT_CONFIG == 1 were retained. SOURCE-class events evclass = 128 of front and back conversion types evtype = 3 were selected to ensure a high-quality γ-ray data set.

The Galactic diffuse emission was modeled using gll_iem_v07.fits, while the isotropic diffuse component was described by iso_P8R3_SOURCE_V3_v1.txt. The XML source model was generated using the make4FGLxml.py script.
